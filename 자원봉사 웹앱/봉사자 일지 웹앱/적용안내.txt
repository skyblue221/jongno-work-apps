자원봉사 활동일지 수정본 v2.2

대상: 자원봉사 활동일지(봉사자 작성 + 담당자·팀장 확인)
자원봉사 통합 관리 앱과 별개입니다.

이번 추가 수정: A4 출력 배치
- 1페이지에 10회분을 배치하고 남는 칸은 빈 작성란으로 채웁니다.
- 11건부터 다음 페이지로 넘어갑니다.
- 글씨 크기는 유지하고 행 높이를 26mm에서 20mm로 줄였습니다.
- 서명 이미지 크기도 행 높이에 맞춰 조정했습니다.
- 인쇄에서도 제목 셀의 옅은 파란색을 유지하도록 색상 인쇄 CSS를 추가했습니다.
  앱의 인쇄 버튼은 HTML 미리보기를 브라우저에서 인쇄합니다.
  인쇄 설정에서 배경 그래픽을 켜야 하는 브라우저도 있습니다.
  PDF 저장 파일에는 생성 당시 셀 배경색이 포함됩니다.
- 이미 v2 수정본을 적용했다면 이번에는 Code.gs만 전체 교체하고 저장한 뒤,
  담당자용 배포를 새 버전으로 업데이트하면 됩니다.
  출력 변경만을 위해 설치 함수를 다시 실행할 필요는 없습니다.
  봉사자 화면의 버전 표시도 맞추려면 봉사자용 배포 역시 같은 버전으로 업데이트합니다.
- 처음 적용하는 경우에는 아래의 전체 적용 순서를 따릅니다.
- 새로 생성하는 PDF에 적용됩니다. 기존 보관 PDF는 자동으로 다시 만들지 않습니다.
- activity_log_preview.pdf는 가상 자료로 만든 출력 예시입니다.
  1건·10건·11건·긴 내용 10건으로 A4 페이지 수와 배치를 확인했습니다.
  예시는 로컬 PDF 변환 결과이며 실제 Apps Script 변환 시 배치가 조금 다를 수 있습니다.

기준
★ 자원봉사일지서명 시트에 연결된 현재 Apps Script 프로젝트에서
Code.gs, Index.html, Admin.html을 읽어 비교한 뒤 수정본을 만들었습니다.
현재 코드에는 알림 메일의 담당자 화면 주소가 이미 들어 있었으며, 그대로 보존했습니다.
기존에 첨부한 코드와 현재 코드의 차이는 그 담당자 주소 설정 한 곳이었습니다.

적용 순서
1. 사용 중인 자원봉사 일지 프로젝트에서 위 세 파일을 각각 전체 교체하고 저장합니다.
   프로젝트 이름: 자원봉사 일지
   확인한 프로젝트 주소:
   https://script.google.com/u/0/home/projects/10anq1xDFqKXbCnXPEi9DXD9d5xZyJULL2Cwcur9wUUCwteEASKvNzPWs/edit
2. 편집기의 함수 선택에서 installActivityLogMaintenance를 골라 한 번 실행합니다.
   - “활동내용 문구” 탭이 없으면 만들고 첫 행만 넣습니다.
   - 기존 알림·보관 트리거를 새 내부 처리 함수로 전환합니다.
   - 알림 확인은 매일 오전 9시, PDF 보관은 오전 2시로 유지합니다.
   - 알림 발송일(13·16·28·1일), 담당자 링크와 보관 폴더 설정을 유지합니다.
   - 실제 메일을 즉시 보내거나 실적/명단을 초기화하는 함수가 아닙니다.
   - setupAll을 다시 실행할 필요는 없습니다.
3. 배포 > 배포 관리에서 “봉사자용”과 “담당자용” 배포를 둘 다 업데이트합니다.
   먼저 봉사자용을 새 버전으로 배포하고, 담당자용은 방금 생성한 같은 최신 버전을 선택합니다.
   두 배포의 실행 계정과 접근 범위는 현재대로 유지합니다.
4. 아래의 기존 두 주소를 각각 새로고침합니다.
   화면에 “활동일지 v2.2 · A4 10회 출력”이 표시되는지 확인합니다.

추천 문구 등록
“활동내용 문구” 탭에 아래 세 열을 입력합니다.
A: 프로그램 / B: 활동내용 / C: 사용(Y/N)
- 프로그램 이름이 일치하고 사용이 Y인 문구를 보여줍니다.
- 프로그램을 비우거나 *를 쓰면 모든 프로그램의 공통 문구입니다.
- N 또는 빈 사용값은 추천하지 않습니다.
- 예시(직접 검토 후 입력): 배식 / 식사 준비 및 배식 지원 / Y
- 지정된 문구가 없으면 추천 항목만 비어 있고 직접 작성은 가능합니다.
- 이전에 봉사자가 제출한 원문은 추천 목록에 사용하지 않습니다.
- 다른 봉사자의 개인정보를 공통 문구에 넣지 마세요.

수정 사항
1. 서명파일 저장 등 내부 함수는 봉사자 화면에서 직접 호출할 수 없도록 변경.
   수동 PDF 보관·알림 함수에는 관리자 확인을 추가.
   자동 처리에는 외부에서 직접 호출할 수 없는 별도 함수 사용.
2. 새 PDF 생성 → 파일 크기 확인 → 시트에 새 파일 ID 기록·확인 → 기존 PDF 정리.
   다른 일지가 이전 파일을 참조하면 정리하지 않음.
3. 잘못된 날짜의 자동 보정(예: 2월31일을 3월로 바꾸는 것) 차단.
   미래 활동일·미래 생년월일 차단. 윤년 날짜는 허용.
4. 추천 목록은 담당자가 정한 문구만 사용. 자유 입력은 유지.
5. 두 화면에 서버 버전 표시 추가.

보존한 운영 방식
이름+전화 뒤4자리 본인 확인, 미등록봉사자 작성, 담당자·대직·팀장 확인,
식사시간 수동 조정, 실적 선입력, 현재 명단·활동원본·서명·기존 보관 폴더.
기관 드라이브 공유 권한이나 담당자 앱의 기관계정 제한은 변경하지 않았습니다.

PDF 생성·빈 파일·시트 쓰기·읽기 검증 실패 시 이전 파일 보존,
다른 일지 참조 보존, 트리거 전환 반복 실행과 설치 실패 시 기존 트리거 유지.
