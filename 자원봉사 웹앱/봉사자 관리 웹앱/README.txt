   - PEOPLE 등록과 배지 수령 이력 저장은 별개입니다.

   - '다음 입력'은 '다음 반월 구간'으로 표시합니다.
3. 배지 신청 중과 봉사자 수령 완료 구분.
   - 기관 누적시간은 후보 탐색용. VMS에서 누적시간 확인 후 실제 신청을 기록합니다.
   - 기존 예정·추천 완료·선정은 진행 중으로 해석합니다.
   - 기존 지급 완료·수상 및 새 수령 완료만 받은 배지로 계산합니다.
   - 기존 기록값을 일괄 변경하지 않습니다. 예전 상태의 실제 의미는 담당자가 확인합니다.
   - 배지 표에서 수령 완료 처리 가능. 일반 포상 상태 선택지는 유지합니다.
   - 동일하거나 높은 단계의 신청·수령 기록이 있으면 중복 신청 기록을 막습니다.
4. 문자명단의 최근 활동을 최근 참여 기록으로 변경.
   - 자동 체크와 수동 체크 해제 방식은 그대로입니다. 별도 수신제외 기능 없음.
5. 연간보고의 단체 판단 보완.
   - PEOPLE 소속 입력 또는 구분 단체 또는 선택 연도 진우의 기업·단체 표기로 판단합니다.
   - 같은 소속 최소 2명 조건은 제거했습니다.
   - PEOPLE 소속은 현재 명단 정보입니다. 과거 연도별 소속 이력을 복원하지는 않습니다.
6. 진우 원본행을 숫자로 취급하고 날짜형으로 읽힌 행 번호를 숫자로 해석.
   - 다음 진우 가져오기에서 원본행 숫자 서식을 적용합니다.
   - 이번 파일에 없는 기존 기록 보존, 같은 등록번호·유형 갱신 방식 유지.
7. 생년월일 보존과 검사.
   - 기존 잘못된 형식은 수정 화면에서 원문과 경고 표시.
   - 다른 정보를 바꿀 때 기존 값을 유지할 수 있습니다. 연도를 임의로 추정하지 않습니다.
   - 기존 잘못된 값을 모르고 빈칸으로 덮어쓰는 저장은 차단합니다.
   - 앱 신규 등록·수정·CSV 가져오기에서 미래 생년월일 차단.

변경하지 않은 것
- 신규의 의미와 계산, 과거자료·진우 통합통계 계산.
- 감사명단: 해당 연도 활동 5회 이상, 시간·횟수순, 상위 30명 자동 선택.
- 교육·모집연계 별도 집계와 기간별 진우 가져오기.
- 현재 PEOPLE 명단, 포상 기록, 진우 원본 및 Google Sheets 값.
- 실제 배포는 수행하지 않았습니다.
