연결노트 v5 — 프로그램 연도 선택

연결 대상은 기존 ★ 연결노트 시트와 동일합니다.
프로그램현황 한 탭 안에 운영연도 열을 추가하여 구분합니다.
복지정보는 모든 연도에서 공통으로 사용합니다.

적용
1. 사용 중인 연결노트 Apps Script에서 Code.gs와 Index.html을 각각 전체 교체하고 저장합니다.
2. 배포 > 배포 관리 > 기존 배포 수정(연필) > 새 버전 > 배포합니다.
3. 기존의 올바른 웹앱 주소를 새로고침합니다.
https://script.google.com/a/macros/jpurme.org/s/AKfycbxkWrQNxvhFPRzrJEBqyaMsXf8eK8xRzPWUB21dZunxifFLiWmSBCBd006E6mgPrryNSQ/exec
4. “연결노트 v5 · 프로그램 연도 선택” 표시를 확인합니다.
5. 정보 관리의 프로그램 목록을 열면 운영연도 열을 자동으로 추가합니다.
   기존에 연도가 비어 있던 프로그램은 2026년으로 기록합니다.
setupSheets나 별도 초기화 함수는 실행하지 않아도 됩니다.

사용
- 찾기 화면과 정보 관리 화면에서 2026년/2027년 등을 선택합니다.
- 새 프로그램은 현재 선택한 연도로 등록됩니다.
- 기존 프로그램의 연도는 수정 창에서 변경할 수 없습니다.
- 관리자는 2026년을 선택하고 “2027년 목록 준비”를 눌러 다음 해 초안을 만들 수 있습니다.
- 2027년 자료가 이미 하나라도 있으면 중복 복사를 막습니다.
  따라서 전체 복사가 필요하면 내년 개별 프로그램을 새 등록하기 전에 목록 준비부터 하세요.

복사되는 항목
- 숨김 또는 종료 상태를 제외한 해당 연도 프로그램
- 프로그램 이름·대상·담당자·이용료 등 기존 정보
- 다음 해에는 별도의 새 ID를 부여합니다. 올해 자료는 유지합니다.
- 다음 해 모집상태는 “확인필요”, 확인일·확인자·다음확인일은 빈칸으로 시작합니다.
- 일정·기간에 적힌 2026년 날짜, 담당자, 이용료, 모집정보는 담당자가 직접 확인해 수정하세요.
- 확인함 또는 수정 저장을 하면 선택 연도의 해당 프로그램만 확인 처리됩니다.

기본 표시 연도
현재 날짜와 같거나 이전인 자료 중 가장 최근 연도를 기본으로 엽니다.
2027년이 되어도 2027년 자료가 없다면 2026년 자료를 계속 볼 수 있습니다.
2027년 자료가 준비되어 있으면 2027년부터 그 자료가 기본으로 열립니다.
이전 연도 자료도 연도 선택으로 다시 조회할 수 있습니다.

함께 포함
모집유형 드롭다운·자동 확인·저장 검증·변경이력,
“프로그램 정보 확인 기록 없음” 문구와 수정 창 X·바깥 클릭·Esc 닫기.

검증
가상 시트에서 기존 열 보존, 연도 분리, 중복 복사 차단, 새 ID,
확인 기록 초기화, 기존 연도 보존, 관리자 권한, 연도별 저장,
화면 선택 동기화와 기존 저장 회귀 테스트를 통과했습니다.
실제 시트나 배포에는 이번 변경을 적용하지 않았습니다.
