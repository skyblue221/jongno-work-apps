후원품 나눔 도우미 수정본

적용 방법
1. 이 앱의 Apps Script 프로젝트에서 Code.gs와 Index.html을 각각 이 압축파일의 전체 내용으로 교체합니다.
2. 저장한 뒤 배포 > 배포 관리 > 수정 > 새 버전으로 기존 웹앱 배포를 업데이트합니다.
3. 기존 앱 주소를 다시 열어 사용합니다. 실제 프로젝트나 배포에는 아직 적용하지 않은 파일입니다.

반영 내용
- 같은 날짜·물품·수령자가 겹치는 별도 배분도 고유 기록ID로 구분합니다.
- 음수·잘못된 수량을 저장 전에 검사합니다.
- 수령자나 수령 내용이 바뀌면 해당 서명을 다시 받고, 기관 인수증 내용이 바뀌면 회수 상태를 초기화합니다.
- PDF 저장 실패를 성공으로 표시하지 않고, 서명을 유지한 채 재시도할 수 있게 합니다.
- 시트 일부만 저장된 오류는 복구한 뒤 재시도하도록 하고, 같은 화면의 같은 저장 요청을 재시도해도 중복 저장되지 않게 합니다.
- 개인 수령증 작성 시 주소 또는 생년월일을 선택합니다. 선택한 항목이 서명 화면과 출력물에 이어집니다.
- 물품 선택 목록과 재고 화면에 ‘목록에 없는 후원품 등록’ 링크를 넣었습니다. 새 창에서 등록하고 ‘등록 후 새로고침’을 누르면 재고를 다시 읽습니다.
  폼 주소: https://docs.google.com/forms/d/e/1FAIpQLSdFv6PF9OE8ac1YFcNvo2Q-MVCW1wAA5lnunsR5EDa6tuQZww/viewform
  설문 내용과 응답의 실제 등록 시트 연결은 확인하지 못했습니다. 앱과 연결된 시트에 등록되고 재고가 남은 물품만 선택 목록에 나옵니다.
- 개인정보 안내를 실제 처리 방식에 맞췄습니다. 휴대폰 서명을 위한 임시 파일, PDF 저장 후 임시 파일 휴지통 이동, 서버·Drive를 사용하는 엑셀 내보내기를 구분합니다.

자동 추가되는 내부 항목
배분·폐기 시트에 ‘앱기록ID’ 열을 추가하며 기존 열 배치와 설정을 유지합니다.
숨김 ‘앱_작업기록’ 시트와 임시 복구용 시트·파일을 사용합니다. 처리·복구 중에는 이 항목을 이름 변경하거나 삭제하지 마세요. 성공한 작업의 복구용 사본은 정리하고, 복구를 확인하지 못한 경우에는 남겨둡니다.
과거 기록은 기존 발급·배분 내용을 대조해 연결합니다. 서로 맞지 않는 기록은 임의로 수정하지 않고 대조 필요 메시지를 표시합니다.

검증
가상 Apps Script 시트·Drive 환경에서 독립 배분 수정, 중복 재시도, 저장 오류 복구, 서명 초기화, 주소·생년월일 유지, 입고일별 재고, 폐기 수정, 수식 보존을 확인했습니다.
실제 Chromium에서 화면 시작, 선택·출력 항목, 잘못된 수량 거부, PDF 실패·재시도를 확인했습니다. 이 화면 시험의 서버 호출은 모의 응답입니다.
실제 기관 시트와 배포 환경에서의 최종 동작은 적용 후 확인이 필요합니다.

시작 화면 오류 대응 추가
Unexpected token class 오류에 대응하여 Index.html의 자바스크립트 문자열 안 HTML 시작 기호를 이스케이프했습니다. 자바스크립트 구문 구조와 실행 값이 동일함을 검사했고, 실제 Chromium의 직접 로딩 및 document.write 로딩 시험을 통과했습니다. Apps Script 배포 환경의 재확인은 필요합니다.
이번 오류 대응은 Index.html만 바뀌었습니다. 직전 수정본의 Code.gs를 이미 적용했다면 Index.html만 전체 교체 후 새 버전으로 배포하세요.

명단 입력 기준 통일
가정 배분 명단의 주소·생년월일은 위쪽에서 한 번만 선택합니다. 개별 선택칸은 제거하고 붙여넣기 예시·표 제목·추가하는 사람·수령증·저장 요청에 같은 기준을 적용합니다. 위 선택을 바꾸면 전체 명단에 반영합니다. 기존 입력값은 지우지 않으므로 바꾼 기준에 맞춰 내용을 확인하세요. 기준을 바꾸면 기존 화면 서명은 초기화합니다. 이미 저장된 과거 수령증이나 상품권 입력은 이 변경 대상이 아닙니다.

자동 저장 PDF의 셀 색상 보완
서버의 HTML→PDF 변환 전 셀 배경색을 background-color 및 bgcolor에 명시합니다. 회색 제목칸과 노란 합계칸에 적용하며, 기존 내용·서명·병합 구조를 유지합니다. 이번 변경 파일은 Code.gs입니다. 직전 수정본을 적용했다면 Code.gs만 전체 교체 후 새 버전으로 배포합니다. 이미 생성된 PDF는 변경되지 않습니다. 실제 서버 변환 결과는 적용 후 새 PDF로 확인해야 합니다.

[2026-11-05 추가] 배분에서 상품권 번호 고르기

- 실물 번호를 보고 체크하거나 「앞에서부터 N장 고르기」를 누르세요. 위쪽 번호부터 받는 분 순서대로 나눠 담겨요.

- 관리대장에 없는 상품권이면 관리자 화면에서 「번호 없이 수량만 내보내기」를 체크하세요.
