시작 화면 오류 대응 추가
Unexpected token class 오류에 대응하여 Index.html의 자바스크립트 문자열 안 HTML 시작 기호를 이스케이프했습니다. 자바스크립트 구문 구조와 실행 값이 동일함을 검사했고, 실제 Chromium의 직접 로딩 및 document.write 로딩 시험을 통과했습니다. Apps Script 배포 환경의 재확인은 필요합니다.

명단 입력 기준 통일

서버의 HTML→PDF 변환 전 셀 배경색을 background-color 및 bgcolor에 명시합니다. 회색 제목칸과 노란 합계칸에 적용하며, 기존 내용·서명·병합 구조를 유지합니다. 이번 변경 파일은 Code.gs입니다. 직전 수정본을 적용했다면 Code.gs만 전체 교체 후 새 버전으로 배포합니다. 이미 생성된 PDF는 변경되지 않습니다. 실제 서버 변환 결과는 적용 후 새 PDF로 확인해야 합니다.
